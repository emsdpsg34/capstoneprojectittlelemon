# Little Lemon Restaurant App

A modern, responsive restaurant website built with React, featuring online ordering, table reservations, and a beautiful user interface.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with beautiful UI on all devices
- **Online Menu**: Browse and order from our Mediterranean cuisine
- **Table Reservations**: Easy booking system with form validation
- **User Authentication**: Login and signup functionality
- **Shopping Cart**: Add items to cart and proceed to checkout
- **Modern UI**: Clean, professional design with smooth animations

## 🛠️ Tech Stack

- **React 19** - Latest React with modern features
- **React Router** - Client-side routing
- **Styled Components** - CSS-in-JS styling
- **Formik & Yup** - Form handling and validation
- **SweetAlert2** - Beautiful alert dialogs
- **CSS3** - Modern styling with Flexbox and Grid

## 📱 Pages

- **Home** - Hero section, specials, and about information
- **Menu** - Full menu with cart functionality
- **Reservations** - Table booking form
- **About** - Restaurant story and information
- **Login/Signup** - User authentication
- **Checkout** - Order completion
- **Confirmation** - Order success page

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd capstone-app
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser
